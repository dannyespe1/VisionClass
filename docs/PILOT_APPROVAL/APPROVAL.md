# Aprobación institucional del piloto

Fecha de aprobación: 2026-10-02

Código documental: `PROTO-TSIS-PILOTO-001-2026`

Rol aprobador: autoridad institucional

Estado: `APPROVED_WITH_CONDITIONS`

## Decisión

La evidencia presentada por el propietario del piloto autoriza la prueba de validación con estudiantes reales bajo las condiciones del protocolo aplicable.

## Alcance autorizado

- piloto con estudiantes reales;
- calibración local previa obligatoria, conservando el método probado hasta una nueva decisión aprobada;
- uso local de cámara;
- doble observación obligatoria.

La autorización no modifica los límites de privacidad del sistema: no habilita identificación biométrica ni transmisión o almacenamiento de imágenes, video, audio, landmarks o material visual crudo.

## Custodia y minimización

El documento fuente permanece bajo custodia externa del responsable del proyecto. El repositorio conserva únicamente los metadatos no sensibles necesarios para trazabilidad; no contiene una copia del PDF, la identidad personal del firmante ni una huella del archivo.

## Condiciones operativas

La aprobación institucional permite preparar la activación, pero el despliegue debe mantener el consentimiento vigente, el procesamiento EDGE, el apagado verificable de cámara y workers, el rol independiente de observador y el rollback documentado. Antes de incorporar estudiantes se debe completar el preflight manual con cuentas de prueba y confirmar la migración y las variables en el entorno objetivo.
