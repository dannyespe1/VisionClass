# Contrato de interpretación para interfaces futuras

PR32 no añade un panel de producto; los paneles se implementan en PR35–PR37. Todo consumidor futuro del informe debe mostrar, junto a cada resultado:

1. “Las asociaciones no prueban causalidad ni miden directamente atención interna.”
2. “Autoinforme, orientación visible, interacción, microevaluación e inferencia son constructos distintos.”
3. Número de participantes, número de pares, intervalo de incertidumbre, faltantes y `no_observable`.
4. Clasificación del análisis (`SYNTHETIC_ONLY_NOT_CONFIRMATORY` o la clasificación aprobada correspondiente).
5. Versión de protocolo, manual, configuración y código.

Está prohibido mostrar una discrepancia como error del participante, diagnóstico o certeza sobre un estado cognitivo. No debe ocultarse una muestra insuficiente ni reemplazarse un valor ausente por cero.
